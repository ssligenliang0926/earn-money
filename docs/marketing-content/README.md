## 核心卖点（所有内容统一口径）

1. **无需登录**：0 注册、0 邮箱，打开即用；
2. **数据不上传**：纯前端计算，无后端无数据库，断网（DevTools Offline）验证全部可用；
3. **免费**：功能无付费墙（页面有 AdSense 广告，用于覆盖服务成本——对外话术见下方合规说明）；
4. **轻快**：纯静态页面、无框架无构建、秒开、移动端适配。

## 平台策略摘要

- **知乎**：选关注数 >1000 的问题，48 小时内回答；价值先行、链接后置；02 篇配"断网测试"截图最有说服力；四个回答相互导流（主页置顶 01）。
- **V2EX**：只发「分享创造」节点一次，语气平实不浮夸；发布后当天回复所有评论；后续在相关提问（"纯前端工具""数据隐私"类）下自然引用，不重复发广告。
- **微博**：140 字内、标签 2-4 个、必配截图；午间/晚间发布；按 4 周节奏表执行。
- **即刻**：产品故事口吻，#独立开发 圈子；"更新日志"与"用户反馈"两类内容在该平台表现最好。
