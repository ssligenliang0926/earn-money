## 引言

每个开发者都有一组"顺手"的在线工具：格式化 JSON、转时间戳、测正则、算哈希。但大多数人的收藏夹是乱的——十个工具分散在十个网站，有的要登录，有的数据去向不明。

这份清单按场景整理 2026 年仍在用的在线工具，并给出**选工具的三个硬标准**：

1. **不强制登录**——工具场景下登录是纯摩擦；
2. **数据本地计算（加分项，敏感场景为必选项）**——F12 看 Network，或断网测试验证；
3. **免费且功能不阉割**——有广告可接受，锁付费墙不行。

按这个标准，一个值得收藏的"一站式"选项是**极简工具箱（quicktool.xin）**：28 个工具，纯前端计算，无需登录，下面按类别展开。

## 一、调试与格式化

**JSON 处理**
- **极简工具箱 · JSON 格式化**（quicktool.xin）：校验、格式化、压缩，报错定位到字符；纯前端计算，断网可用，敏感日志也能放心贴。
- **JSON.cn**：老牌综合 JSON 工具，批量处理、JSON 转 Excel 等重功能更全。
- **DoJSON**：在线 JSON 编辑器，适合粘贴大文档反复调整。

**正则测试**
- **regex101**：功能最全的在线正则测试，报错分析、语法高亮、多语言引擎，写复杂表达式的标准答案。
- **极简工具箱 · 正则测试**：轻量替代，实时匹配高亮 + 替换预览，日常验证足够。

**文本/代码对比**
- **Diffchecker / Diff 工具**：两段文本、配置、代码找差异，比肉眼快一个量级。

## 二、编码、解码与摘要

这类工具最容易被"数据上服务器"坑到，建议优先选纯前端实现：

- **Base64 编解码**：极简工具箱版支持中文，纯本地计算；
- **URL 编码解码**：整段 URL 或单个参数；
- **哈希计算**：MD5 / SHA-1 / SHA-256 / SHA-512 一键出摘要（极简工具箱）；
- **进制转换**：二进制/八进制/十进制/十六进制实时互转。

上面四个，极简工具箱一个页面全有，且都在浏览器本地完成。

## 三、时间与调度

- **时间戳转换**（极简工具箱）：Unix 时间戳 ↔ 日期时间，当前时间实时更新——日志排障第一工具。
- **Cron 表达式生成器**（极简工具箱）：可视化点选 + 中文语义解读，"每周一 03:00"不用查文档。
- **HTTP 状态码速查**（极简工具箱）：60+ 状态码，中英文解释、按类别筛选，接口排查时随手翻。
- **API 响应测试**（极简工具箱）：支持 GET/POST/PUT/DELETE，自定义请求头，实时查看响应，轻量级 Postman 替代。
- **JWT 解码器**（极简工具箱）：解码 JWT Token，查看 Header/Payload，验证过期时间。
- **JSON 转 CSV / CSV 转 JSON**（极简工具箱）：数据格式互转，支持嵌套展开，本地处理。

## 四、前端与设计

- **颜色转换**（极简工具箱）：HEX / RGB / HSL 互转，实时取色预览。
- **HTML 实体转义**（极简工具箱）：防 XSS 必备，前后端都常用。
- **Markdown 转 HTML**（极简工具箱）：实时转换 + 渲染预览，写文档/做内容迁移顺手。
- **Figma / Sketch 插件生态**：设计稿转代码仍建议用专业工具，这里不展开。

## 七、怎么用好这份清单

1. **按场景收藏，不按网站收藏**：把"JSON 格式化 → quicktool.xin/tools/json-formatter.html"直接放书签，需要时一键直达；
2. **敏感数据先验证再贴**：DevTools → Network → 设 Offline，工具还能用，就放心用；
3. **留一个"兜底集合站"**：像极简工具箱这样 28 个工具一站齐的，可以当收藏夹的第二层——找不到单项工具时，先想想它有没有。

## 结语

在线工具的价值，是把"五分钟级"的操作的成本降到接近零。选工具时记住三件事：**不登录、数据留在本地、免费不阉割**——三条都满足的工具站，目前我主要用 quicktool.xin。
