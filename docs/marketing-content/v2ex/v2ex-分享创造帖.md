## 帖子正文

各位好，是一名后端开发。

平时工作里经常要格式化 JSON、转时间戳、解码 Base64、算个哈希，这些"五分钟级"的操作我用了很多在线小站，体验却不太一致：有的要登录，有的明显把输入发到了服务端，有的广告比工具还大。

嫌麻烦，就自己做了一个：**极简工具箱** —— quicktool.xin

### 有什么

28 个工具，大致分四类：

**开发向**
JSON 格式化校验（报错定位到字符）、Unix 时间戳转换、Base64 编解码、URL 编解码、MD5/SHA 哈希计算、进制转换、正则测试、UUID 批量生成、密码生成器、Cron 表达式生成（附中文解读）、HTTP 状态码速查（60+）、Markdown 转 HTML、HTML 实体转义、**API 响应测试**（GET/POST/PUT/DELETE）、**JWT 解码器**

**数据转换向**
**JSON 转 CSV**（支持嵌套展开）、**CSV 转 JSON**（支持文件上传和粘贴）

**设计/办公向**
颜色转换（HEX/RGB/HSL + 取色）、二维码生成（支持中文，导出 PNG）、图片压缩、图片转 Base64（Data URL/CSS/HTML）、Markdown 实时编辑预览、字数统计

**生活向**
金额转中文大写、单位换算（8 大类）、BMI 计算、日期天数差、房贷计算器（等额本息/等额本金对比）

### 几个设计原则

1. **无需登录、无需注册**。工具场景下我认为登录是纯摩擦，一个都没有做。
2. **纯前端计算，数据不离开浏览器**。整站没有后端、没有数据库，输入内容不会发往任何服务器。图片压缩也是本地 Canvas 完成的。可以打开 DevTools 把 Network 设为 Offline 验证——断网状态下所有工具都还能用。（API 响应测试工具除外，它需要发送 HTTP 请求来测试目标 API）
3. **免费**。页面有少量广告，用来覆盖服务成本，工具功能本身没有任何付费点。
4. **极简直观**。纯静态页面、无构建、无框架，秒开；手机和桌面端都适配。

## 评论区应对预案

| 可能的评论 | 建议回复 |
|------------|----------|
| "怎么盈利？" | 广告（AdSense），覆盖域名/服务成本；工具功能全部免费无付费墙。 |
| "为什么不发个 PWA？" | 可以，但定位是"随开随用的书签站"，先保证核心体验，后续考虑。 |
| "Base64 支持文件吗？" | 目前文本为主，文件版（图片转 Base64 已支持图片）在考虑清单里，欢迎提 issue。 |
| "广告多吗？" | 首页 2 个广告位，工具页 1 个；不影响操作区。 |
| "无后端不怕被注入吗？" | 纯静态托管 + 全站 HTTPS，输入只做本地计算和 HTML 实体转义输出；也欢迎看源码。 |
| "收藏了 +1" | 谢谢支持，有想要的新工具欢迎 issue。 |
