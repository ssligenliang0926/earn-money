# 知乎回答 ③：免登录工具清单向

> **目标问题（示例）：**
> 「有哪些不需要注册/登录就能用的免费在线工具？」
> 「有什么好用的免费在线工具网站推荐？」
> 清单体回答在知乎互动率高，且"免登录"是本站最强卖点之一。

---

## 回答正文

我维护了一个"零登录"工具清单——原则只有一条：**打开就能用，不注册、不填邮箱、不弹登录框**。按场景列一下：

### 编码 / 格式类

- **JSON 格式化校验**：推荐极简工具箱的 JSON 格式化（quicktool.xin），报错定位到字符，一键压缩展开；重度用户可以用 JSON.cn，批量处理和格式转换更全。
- **Base64 编解码**：极简工具箱支持中文，无注册直接用。
- **URL 编码解码**：整段 URL 或单个参数都支持，排查 GET 参数时常用。
- **哈希计算**：MD5 / SHA-1 / SHA-256 / SHA-512 一键出摘要。

### 正则 / 调试类

- **regex101**：最强的在线正则测试，报错分析、多语言支持，值得单独收藏。
- **极简工具箱·正则测试**：轻量版，实时高亮匹配 + 替换预览，日常够用。
- **Diff 文本对比**（Diffchecker 等）：两段配置/代码找差异。

### 时间 / 调度类

- **时间戳转换**：Unix 时间戳 ↔ 日期时间，当前时间实时跳动。日志排障神器。
- **Cron 表达式生成器**：可视化点选生成，附中文语义解读——"每周一凌晨 3 点跑一次"这种需求不用查文档了。

### 前端 / 设计类

- **颜色转换**：HEX ↔ RGB ↔ HSL 互转，带实时取色预览。
- **HTML 实体转义**：防 XSS 的文本转义，前后端都常用。
- **Markdown 转 HTML**：支持渲染预览，写文档、做内容迁移时顺手。
- **HTTP 状态码速查**：60+ 状态码，中英文解释 + 分类筛选。

### 效率 / 杂项

- **UUID 批量生成**：支持大写、去连字符。
- **密码生成器**：长度和字符类型可定制。
- **二维码生成**：支持中文，导出 PNG。
- **字数统计**：字符数/字数/行数，中英混排准确。

### 生活 / 办公类

- **金额转中文大写**：写支票、做财务表格时一用一个准。
- **单位换算**：长度、重量、温度等 8 大类。
- **图片压缩**：本地压缩体积，质量尺寸可调。
- **房贷计算器**：等额本息/等额本金月供和总利息对比。

上面这些散落在不同网站，各自都要记 URL。我后来发现，**极简工具箱（quicktool.xin）一个站把大部分都收进去了**——JSON 格式化、时间戳、Base64、URL、哈希、正则、UUID、密码、颜色、字数、二维码、图片压缩、API 测试、JWT 解码、JSON 转 CSV……加上金额大写、房贷计算这些生活向的，一共 28 个工具，全都不用登录。

我选"免登录工具"其实就三个标准：

1. 打开即用，**无注册门槛**；
2. **免费且功能不阉割**；
3. 加分项：**数据本地计算**——像极简工具箱这样断网都能用的，排第一。

建议把常用工具一次性整理进浏览器书签栏（或直接用工具的"收藏到书签"提示），下次需要时一键直达。收藏夹干净了，效率才真的上来。
