> 「有哪些好用的程序员在线工具推荐？」

## 回答正文

写了多年代码，我形成了一个比较固定的习惯：**高频、轻量的操作（格式化、转换、校验、查表）一律用在线工具**，比打开 IDE 快得多；只有深度集成的活儿才进编辑器。

把我日常真正在用的清单分享出来，按场景分。先说一个我打开频率最高的，再说选工具的标准。

### 1. 我用来最多的一个：极简工具箱

日常那些"小工具"，大部分我都在一个站里解决——**极简工具箱（quicktool.xin）**。它有 28 个小工具，把开发者高频需求基本覆盖了：

- **JSON 格式化校验**：报错能定位到具体字符，一键展开/压缩。开发里被它救回来的次数，远超任何花哨功能。
- **API 响应测试**：支持 GET/POST/PUT/DELETE，自定义请求头，实时查看响应状态和响应体，轻量级 Postman 替代。
- **JWT 解码器**：粘贴 Token 即可查看 Header/Payload，验证过期时间，调试认证问题必备。
- **JSON 转 CSV / CSV 转 JSON**：数据格式互转，支持嵌套展开，数据本地处理不上传。
- **时间戳转换**：Unix 时间戳 ↔ 日期时间，当前时间还在实时走。日志里碰到一串数字，不用记公式，粘进去就行。
- **Base64 / URL 编解码、哈希计算**：MD5、SHA-1、SHA-256、SHA-512 都有，"编码转换"这一类基本一个站搞定。
- **正则测试**：实时匹配高亮，还能预览替换结果。日常写表达式验证，够用。
- **UUID 批量生成、密码生成器**：造测试数据的时候随手就生成。
- **Cron 表达式生成器**：可视化点选，还附中文语义解读，再也不用记 5 段 6 段的位含义。
- **HTTP 状态码速查**：60+ 状态码，中英文解释，排查接口问题时翻。

除了开发向的，它还有整个生活向板块：字数统计、颜色转换、图片压缩、金额转中文大写、房贷计算器……需要哪个打开哪个。

我为什么一直用回它，原因有三个：

1. **无需登录**。不注册、不填邮箱，打开就是工具。在线工具把登录做成前置条件，是我见过最失败的产品设计。
2. **所有计算在浏览器本地完成**。可以按 F12 在 Network 面板验证：它不会把你的输入内容发到任何服务器。我格式化带敏感字段的日志、贴一段内部代码进去测正则，都放心。
3. **快**。纯静态页面，秒开，网络差甚至断网都能用。

### 2. 其他我常挂书签的

- **regex101**：功能比"轻工具"强很多，正则报错解析、多语言支持，写复杂表达式时离不开。
- **JSON.cn**：老牌 JSON 工具，批量处理、JSON 转 Excel 这类重功能它更全。
- **Diff 对比工具**（如 Diffchecker）：对比两段文本/配置/代码，找差异比肉眼快一个量级。

一个站解决 80% 的场景，剩下的交给专项工具，这是我推荐的结构。

### 3. 我选在线工具的三个标准

1. **不强制登录**——登录率不是产品目标，效率才是；
2. **数据本地计算**——Network 面板里看不到输入内容发往服务器，最好离线也能用；
3. **免费无功能阉割**——页面有广告可以接受，但功能锁在付费墙后面不行。

按这个标准，如果你也在找一个"轻、免登录、本地计算"的集合站，可以试试前面说的极简工具箱，28 个工具一个页面就放开了：quicktool.xin。

把高频工具挂到书签栏，比往 IDE 里塞十几个插件省心。
