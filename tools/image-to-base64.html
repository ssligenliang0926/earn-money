使用说明

选择或拖入图片后，工具立即在浏览器本地将图片读取为 Base64 编码，并生成带 MIME 前缀的 Data URL，可直接嵌入 HTML、CSS 或 JSON 中使用。

切换「输出格式」可获得不同用途的片段：Data URL 适合直接粘贴；CSS 格式自动包裹 background-image 语句；HTML 格式生成完整的 img 标签。

Base64 编码后体积约增大 33%，建议仅对小图标、小图片使用内联 Base64，大图仍建议使用独立文件引用。

常见问题

图片转 Base64 后体积为什么会变大？

Base64 用 4 个可打印字符表示 3 个字节，因此编码后体积约为原始的 4/3 倍（增大 33% 左右），再加上 data:image/png;base64, 前缀。这是编码原理决定的，属于正常现象。

Data URL 可以直接用在哪些地方？

可以直接作为 HTML 中 img 标签的 src、CSS 中 background-image 的 url()、以及 JSON 数据中传递图片内容，无需额外请求图片文件，适合小图标和需要单文件分发的场景。

我的图片会被上传到服务器吗？

不会。转换全程使用浏览器 FileReader 在本地完成，图片只存在于当前页面内存中，关闭页面即释放，不会发送到任何服务器。

转换大图片会卡吗？

Base64 字符串很长时，复制和渲染会消耗较多内存。建议仅对 2 MB 以内的小图使用本工具；大图请先用「图片压缩」工具减小体积后再转换。
