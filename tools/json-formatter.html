使用说明

将 JSON 文本粘贴到输入框，点击「格式化」即可校验语法并美化输出；点击「压缩」会去除所有空白字符，得到单行 JSON，方便通过接口传输。

若 JSON 存在语法错误，页面会给出错误原因，并定位到具体的行和列，帮助你快速修复。

常见问题

JSON 校验失败的常见原因有哪些？

最常见的是：键名没有加双引号、使用了单引号、对象或数组末尾多逗号、混入了中文引号或中文逗号、添加了注释等。标准 JSON 不支持注释和尾逗号，本工具会把错误定位到具体行列，方便快速排查。

格式化和压缩有什么区别？

格式化会按选定的缩进对 JSON 进行换行和缩进排版，便于阅读和排查问题；压缩则会移除所有换行、缩进和多余空白，输出单行 JSON，体积更小，适合网络传输。

我的数据会被上传吗？

不会。所有解析均在你的浏览器本地完成，页面不会发起任何网络请求，可以放心处理包含敏感信息的 JSON。
