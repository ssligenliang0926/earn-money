关于 JWT

        
JWT（JSON Web Token）是一种开放的行业标准（RFC 7519），用于在各方之间安全地传输信息。JWT 由三部分组成：Header（头部）、Payload（载荷）和 Signature（签名）。

        
Header 通常包含令牌类型（JWT）和签名算法（如 HMAC SHA256、RS256）。

        
Payload 包含声明（claims），即关于实体（通常是用户）和其他数据的声明。标准声明包括 iss（签发者）、exp（过期时间）、sub（主题）等。

        
Signature 用于验证消息在传输过程中没有被篡改。签名通过 Header 中指定的算法对 Header 和 Payload 进行编码后计算得出。

        
本工具仅解码 JWT Token，不会验证签名有效性（需要密钥），也不会上传您的 Token 到任何服务器。

      

    

  


  


  

    
常见问题

    
JWT Token 安全吗？

    
JWT 本身是 Base64URL 编码的，不是加密的。这意味着任何人都可以解码查看内容。JWT 的安全性依赖于签名验证，只有持有正确密钥的服务端才能验证 Token 的有效性。请妥善保管您的 JWT，不要在前端代码中硬编码密钥。

    
如何验证 JWT 签名？

    
本工具仅解码 Token，不验证签名。要验证签名，您需要使用服务端代码配合正确的密钥。常见的 JWT 验证库包括：jsonwebtoken（Node.js）、PyJWT（Python）、jwt（Java）等。

    
JWT 和 Session 有什么区别？

    
JWT 是无状态的，所有信息都存储在 Token 中，服务端不需要保存会话信息。Session 是有状态的，服务端需要保存会话数据。JWT 适合分布式系统和 API 认证，Session 适合传统的 Web 应用。
