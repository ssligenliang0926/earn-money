使用说明

输入阿拉伯数字金额后实时转换为中文大写，可直接复制用于支票、发票、收据、合同等财务场景。

转换遵循财务规范：整数部分以「元」结尾，无角分时补「整」；角分均为 0 时输出「整」；连续多个 0 只读一个「零」。

示例：1234.56 → 壹仟贰佰叁拾肆元伍角陆分；100 → 壹佰元整；0.5 → 伍角。

常见问题

大写数字用的是哪一套？

采用财务规范的正体大写：零壹贰叁肆伍陆柒捌玖拾佰仟万亿元角分整，与银行支票、发票填写要求一致。

什么时候需要写「整」字？

金额到「元」为止（没有角分）时写「元整」；有角无分时写「角整」；有分时不写「整」。例如 100 → 壹佰元整，0.50 → 伍角整，0.56 → 伍角陆分。

中间的 0 怎么读？

数字中间的连续 0 只读一个「零」，例如 1001 → 壹仟零壹元整；万、亿级单位前的 0 不重复读零，例如 100000001 → 壹亿零壹元整。

支持多大的金额？

支持整数部分最多 15 位（即千万亿级，999 万亿以内），小数最多两位，超出范围会给出提示。

我的金额数据会被上传吗？

不会。转换完全在浏览器本地完成，可放心处理真实财务数据。
