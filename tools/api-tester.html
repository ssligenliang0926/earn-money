关于 API 测试

API 测试是开发过程中验证接口功能的重要手段。本工具支持常见的 HTTP 方法（GET、POST、PUT、DELETE），可以自定义请求头和请求体，实时查看响应状态码、响应头和响应体。

与 Postman 等桌面应用相比，本工具的的优势是无需下载安装，打开浏览器即可使用，且所有操作均在本地完成，不会上传数据到服务器。

注意：由于浏览器安全策略（CORS），部分 API 可能无法直接调用。建议配合浏览器插件（如 CORS Unblock）使用，或在支持跨域的测试环境运行。

常见问题

为什么我的请求失败？

最常见的原因是 CORS（跨域资源共享）限制。浏览器默认不允许前端代码向不同域的 API 发起请求，除非目标服务器明确允许。解决方法：1) 使用支持跨域的测试 API；2) 安装浏览器 CORS 插件；3) 在本地搭建代理服务器。

如何测试 POST 请求？

选择 POST 方法后，在请求体区域输入 JSON 格式的数据，例如：{"name": "张三", "age": 25}。然后点击"发送请求"即可。

支持哪些响应格式？

本工具支持 JSON、XML、纯文本等常见响应格式。如果是 JSON 格式，会自动格式化显示。
