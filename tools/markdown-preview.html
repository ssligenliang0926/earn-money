使用说明

在左侧编辑区输入或粘贴 Markdown 文本，右侧会实时渲染预览效果，无需点击任何按钮。

点击「全屏分屏」进入全屏编辑模式，左侧编辑、右侧预览，最大化利用屏幕空间；点击「全屏预览」则只显示渲染结果，适合演示和阅读。

支持 GFM 语法：标题、加粗、斜体、删除线、列表、代码块、表格、引用、链接、图片、分割线等。全屏模式下按 Esc 或点击右上角按钮退出。

常见问题

全屏模式下怎么退出？

按键盘 Esc 键，或点击全屏模式右上角的「退出全屏」按钮即可退出。

支持哪些 Markdown 语法？

支持 GFM（GitHub Flavored Markdown）全部常用语法：多级标题、有序/无序列表、任务列表、加粗、斜体、删除线、行内代码、代码块、链接、图片、引用、表格、分割线等。

内容会被上传到服务器吗？

不会。所有渲染都在你的浏览器本地完成，页面不会上传任何内容，可放心处理未公开的文稿。

和「Markdown 转 HTML」工具有什么区别？

本工具侧重于实时编辑与预览，支持分屏和全屏模式，适合撰写文档时即时查看效果；「Markdown 转 HTML」侧重于将 Markdown 转换为 HTML 代码并复制使用。
