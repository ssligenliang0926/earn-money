关于颜色转换

HEX 常用于 CSS 与网页设计，RGB 常用于屏幕显示与图像处理，HSL 更符合人眼对色相、饱和度、亮度的直觉，适合调色。

三种输入框均可直接编辑，修改任一格式会自动同步更新其他格式与预览；也可以使用取色器快速选色。

所有计算均在你的浏览器本地完成，不会上传到任何服务器。

常见问题

HEX、RGB、HSL 应该用哪个？

写 CSS 时三者均可。HEX 最简短，适合固定色值；RGB 与屏幕像素一一对应，常用于图像与 Canvas；HSL 调整亮度、饱和度最直观，适合做主题配色与悬停态变色。

支持三位简写 HEX 吗？

支持。输入 #fff、#f00 等三位简写会自动展开为六位完整格式（#ffffff、#ff0000）再进行转换。

转换结果会丢失精度吗？

RGB 与 HEX 之间是无损转换；HSL 的色相、饱和度、亮度会四舍五入到整数百分比，回转回 RGB 时可能有 ±1 的通道误差，属于正常现象，视觉上无差异。
