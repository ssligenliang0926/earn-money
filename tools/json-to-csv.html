关于 JSON 转 CSV

JSON（JavaScript Object Notation）和 CSV（Comma Separated Values）是两种常用的数据格式。JSON 适合存储和传输结构化数据，而 CSV 适合表格数据处理和分析。

本工具可以将 JSON 数组转换为 CSV 格式，支持以下功能：

  • 自动提取所有列名
  • 支持嵌套对象展开
  • 支持 UTF-8 BOM（Excel 兼容）
  • 自定义分隔符
  • 数据在浏览器本地处理，不上传服务器

转换后的 CSV 文件可以直接导入 Excel、Google Sheets 或其他数据分析工具。

常见问题

JSON 格式要求是什么？

输入的 JSON 必须是数组格式，每个元素是一个对象。例如：[{"name":"张三","age":25},{"name":"李四","age":30}]。如果是单个对象，工具会自动包装为数组。

如何处理嵌套的 JSON？

默认情况下，嵌套对象会被展开为多列，列名使用点号分隔，如 user.name、user.age。也可以关闭此选项，将嵌套对象转换为 JSON 字符串。

为什么 Excel 打开 CSV 中文乱码？

勾选"添加 UTF-8 BOM"选项可以在 CSV 文件开头添加字节顺序标记，让 Excel 正确识别 UTF-8 编码。
