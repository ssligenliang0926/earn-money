使用说明

在输入框中输入或粘贴 Markdown 文本，页面会实时将其转换为 HTML 代码，无需点击按钮。

支持标题、列表、加粗、斜体、链接、图片、引用、代码块、表格（GFM）、分割线等常用语法；勾选选项后单个换行会转换为 <br>。

点击「渲染预览」可查看排版效果，点击「复制 HTML」即可把转换结果粘贴到网站或富文本编辑器中使用。

常见问题

支持哪些 Markdown 语法？

支持 GFM（GitHub Flavored Markdown）常用语法：多级标题、有序/无序列表、加粗、斜体、删除线、行内代码、代码块、链接、图片、引用、分割线以及表格等。

单个换行为什么没有变成新行？

标准 Markdown 中，段落内的单个换行会被合并为同一段落。如果需要每个换行都生成 <br>，勾选上方的「将单个换行转换为 <br>」选项即可。

Markdown 里写的 HTML 标签会被保留吗？

会。Markdown 中的原始 HTML 会原样输出到结果中。如果转换结果要发布到公开网站且内容来自他人提交，请注意 XSS 风险，建议先做 HTML 过滤。

我的内容会被上传吗？

不会。转换完全在你的浏览器本地完成，页面不会上传任何内容，可放心处理未公开的文稿。
