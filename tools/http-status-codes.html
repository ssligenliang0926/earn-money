使用说明

HTTP 状态码是服务器对客户端请求的三位数字响应，按首位数字分为五类：1xx 信息、2xx 成功、3xx 重定向、4xx 客户端错误、5xx 服务器错误。

在搜索框输入状态码数字、英文名（如 not found）或中文关键词（如 重定向、超时）即可实时过滤；点击上方分类按钮可快速定位某一类状态码。

点击表格任意一行即可复制该状态码数字，方便粘贴到文档或代码中。

常见问题

301 和 302 重定向有什么区别？

301 表示资源已永久迁移，浏览器和搜索引擎会缓存新地址并传递权重，适合域名更换、HTTPS 切换；302 表示临时跳转，原地址仍被视为有效，适合短期活动页跳转。SEO 场景下用错会导致权重不传递。

401 和 403 都是没权限，区别在哪？

401 Unauthorized 表示"未认证"，即服务器不知道你是谁，提供有效凭证（登录、Token）后重试可能成功；403 Forbidden 表示"已认证但无权限"，即使重新登录也无法访问该资源。

502 和 504 都是网关错误，怎么区分？

502 Bad Gateway 是网关收到了上游服务器的无效响应（通常上游服务崩溃或返回异常）；504 Gateway Timeout 是网关在限定时间内没有等到上游响应（通常上游处理太慢或网络阻塞）。排查方向分别是上游服务健康度与超时/性能问题。

429 状态码常见于什么场景？

429 Too Many Requests 表示请求频率超过了服务器的限流阈值，常见于开放 API 的 QPS 限制。客户端应读取 Retry-After 响应头并实施退避重试，避免持续高频请求。
